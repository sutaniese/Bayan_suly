## Accessibility Personalization Demo (Phase 13)

Goal: show that **Botara adapts to the child** (visible changes + parent controls) in under ~3 minutes.

### Pre-demo reset (recommended)

- In Parent Mode, use **Reset demo progress** (clears `localStorage` on this device).
- Reload the page.

### Script (accessibility personalization)

1. **Open app from fresh state**.
2. Enter **child name** and **age**.
3. Choose language (RU/KZ).
4. On **Learning Comfort Setup**, select:
   - **Better visibility** (vision)
   - **Calm focus mode** (focus)
5. Tap **Create adaptive profile**.
6. On **Adaptive Profile Result**, point out:
   - **Large text / larger UI**
   - **High contrast**
   - **Voice instructions** (audio is optional)
   - **No timer**
   - **Simplified tasks / fewer options**
7. Tap **Continue** to the Kazakhstan map and show the UI is larger/clearer.
8. Open **Turkestan → Find the Kazakh Word**:
   - Tap **Explain simpler**
   - Tap **🔊 Read aloud** (or use **Bota Voice Guide**)
   - Complete one question (show **multi-modal feedback**)
9. Open **Parent Mode** (PIN **1234**) and show:
   - **Adaptive Profile** summary (support needs, enabled settings, recommendation summary)
   - Toggle **Gesture Answer Mode**
10. Return to a quest and show **Gesture Mode mock**:
    - **👉 Next** / **✋ Repeat** / **👍 Select**

### Closing line (product message)

```text
Botara adapts to the child instead of forcing every child into the same interface.
```
